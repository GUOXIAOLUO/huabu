## Goal

Fix the runtime TypeError on the default loopback path by ensuring the ten
R4-21 blank-create entry points on both pages pass `canvasId: canvas.id` (or the
equivalent smart-canvas truthy id reference) into `CreationController.createNode`
the same way the R4-22 file-drop and R4-23 clipboard helpers already do.

## Before Owner

- `WorkbenchInteractionController.createCreationController.createNode` rejects
  any request missing `canvasId` (`TypeError: CreationController requires
  canvasId`, interaction-controller.js:335).
- The 10 blank-create entry points in `static/js/canvas.js` and
  `static/js/smart-canvas.js` (5 each) call
  `ensureCreationController().createNode({ ... })` / `ensure...().createNode({ ... })`
  without `canvasId`, even though the very next line already references
  `canvas.project` and the body is gated by `canUseVersionedImageCreation()` /
  `canUseVersionedSmartImageCreation()` which require `canvas.id` to be truthy.
- Verified empirically in a Node sandbox (R4-23 evidence) and by source
  inspection of the R4-21 commit `6694c64`.
- R4-22 (file-drop) and R4-23 (clipboard) helpers correctly pass
  `canvasId: canvas.id` — they are NOT in this card's scope.

## After Owner

- All ten blank-create helpers (5 Classic + 5 Smart) propagate
  `canvasId: canvas.id` into the controller envelope.
- The R4-23 wiring contract is extended from "one `clipboard` source per
  adapter + `canvasId:canvas.id` in the two clipboard helpers" to also pin
  `canvasId:canvas.id` in every R4-21 blank-create helper body.
- A new focused behavioral test drives every blank-create helper with a real
  controller mock and asserts:
  - the controller receives a canvasId matching the page's `canvas.id`;
  - no helper throws the `CreationController requires canvasId` TypeError on
    the default loopback path.
- No behavior change beyond the canvasId propagation; provenance source,
  definition refs, initialConfig, undo/revision/selection projection, and
  retained adapter-owned fragment paths stay exactly as R4-21/R4-22/R4-23
  recorded them.
