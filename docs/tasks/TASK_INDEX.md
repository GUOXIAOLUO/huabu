## WholeHouse Rule

WholeHouse concrete work is primarily delivered as package-defined Skills, Entity/Collection/Catalog definitions,
Workflow templates, Knowledge, Workspace extensions and Integration profiles.

It must not create a second Canvas or permanent industry-specific Core NodeKinds.
