# Workbench Domain Glossary

## Collection

A generic structured multi-item resource owned by a Project. A Collection has
its own schema, ordered items, typed reference cells or literal cells, default
view metadata, and revision. It is independent from Canvas presentation.

## CollectionSchema and CollectionColumn

CollectionSchema defines the reusable columns of a Collection. A
CollectionColumn names the key and the value type accepted by that column.

## CollectionItem and cells

CollectionItem is an ordered row of values, not a Canvas Group membership
record. Literal cells contain values directly; reference cells identify typed
Workbench resources such as AssetVersion, ArtifactVersion, EntityVersion, or
another Collection.

## Group

A Canvas visual organization concept. Group membership and layout are not
Collection item order or Collection data.
